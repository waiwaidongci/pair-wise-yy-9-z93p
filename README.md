# 母液开封与分装放行台（古法蓝晒底片整理室 · 扩建）

母液开封、分装登记、双人双样复核放行的工作台。入口、判定、存档分置三个业务文件：

| 文件 | 职责 |
| --- | --- |
| `src/intake.js` | **入口**：开封登记、分装登记、取样提交、余量/浓度/交接更正。先校验后变更，冲突不产生半截记录。 |
| `src/decision.js` | **判定**：效期、交接、唯一未结束单、浓度合格区间、显影槽占用、双人双样放行结论。纯函数。 |
| `src/archive.js` | **存档**：JSON 原子落盘（临时文件 + rename）、只追加事件履历、旧稿冻结只读、队列与批次履历派生视图。 |

`server.js` 仅做 HTTP 路由：入口层在内存中完成全部校验与变更后，才统一落盘；任何冲突都在写盘前返回 409。

## 运行

```bash
npm start          # http://localhost:3040
npm test           # node --test，规则与 HTTP 端到端共 29 例
```

数据默认保存在 `data/stock-solution-station.json`（首次启动自动播种），可用 `STATION_DB` 指定其他路径。

## 业务规则

- **同一药液批次只允许一张未结束分装单**；已放行、已驳回为终态，终态后可开新单。
- 分装登记前依次校验：批次在效期 → 当班交接已确认 → 无未结束单 → 分装量为正 → 母液余量充足；
  合格浓度还需有空显影槽。任一不过返回 409/400，**不扣余量、不建单、不写事件**。
- 单内登记**分装量、显影浓度、操作者**。显影浓度合格区间为 **12.0%–14.0%**：
  越界同样转**待复核**，但**不占显影槽**；合格单待复核期间占一槽，放行/驳回即释放。
- **复核由另一人连续两次取样**（第二次取样人不得与第一次相同），两次均落合格区间、
  且原批次仍在效期、交接仍确认，才**放行**；任一不满足判**驳回**（终态）。
- **更正**：分装单的分装量/浓度、批次的余量/交接状态可更正。更正会让相关放行**失效并重算**：
  旧放行结论与原取样封存为只读旧稿（`voidedReleases` / `revisions` / `archivedSamples`，对象冻结），
  单据回到待复核，必须重新双人双样；已驳回单归档只读，不可更正。
- 分装量更正联动重算批次余量，会导致负余量或槽位超容时拒绝更正且不留痕。
- 队列、显影槽、批次履历、总账全部由同一份存储现场派生，刷新后一致。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/batches` | 母液开封 |
| PATCH | `/api/batches/:no` | 更正批次余量 / 交接状态 |
| GET | `/api/batches/:no/history` | 批次履历（事件 + 相关分装单与只读旧稿） |
| POST | `/api/orders` | 分装登记 |
| PATCH | `/api/orders/:id` | 更正分装量 / 浓度（放行失效重算） |
| POST | `/api/orders/:id/samples` | 复核取样（第 1 / 第 2 次） |
| GET | `/api/queue` | 分装队列 + 显影槽占用 |
| GET | `/api/ledger` | 全部批次现场与事件流水 |

冲突响应形如 `{"error":"OPEN_ORDER_EXISTS","message":"…","details":{…}}`，状态码 409。
